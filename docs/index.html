The Hermes Standard Companion

A Raspberry Pi 5 preloaded with Multiplug and MultiPlug.Ext.Hermes software for use to integrate with OEM SMT Machines or Machines running a PLC (Programmable Logic Controller).

Note: This product requires software integration to a PLC or third party system.
