# Hermes-Standard-Companion
The Hermes Standard Companion is a [Raspberry Pi 5](https://www.raspberrypi.com/products/raspberry-pi-5/) preloaded with [Multiplug](https://www.multiplug.app/) and [MultiPlug.Ext.Hermes](https://github.com/Industry4/MultiPlug.Ext.Hermes/wiki) software for use to integrate with OEM SMT Machines or Machines running a [PLC](https://en.wikipedia.org/wiki/Programmable_logic_controller) to support [IPC-HERMES-9852](https://www.the-hermes-standard.info/).


* View the [Brochure Website](https://www.the-hermes-standard-companion.info/) for a product overview.
* Read the [Wiki](https://github.com/Industry4/Hermes-Standard-Companion/wiki) for technical support.
* Buy from a [Distributor](https://www.4ir.uk/products/distributors/).
